同机双账号：必须普通 + 无痕（或两个 Chrome 配置）

Chrome 同一配置下，所有普通窗口共享一套 douyin.com Cookie——两个普通标签页不可能同时是两个号。 第二个号请用无痕窗口，并在 chrome://extensions 勾选「在无痕模式下启用」。 抓取后核对账号昵称与 sessionid 指纹，避免覆盖其他账号。

会在同一浏览器窗口临时打开主站，采集主站 UIFID、指纹、SDK Token 和配套密钥。只复制完整导入串，单独 Cookie 不包含全部发送材料。

若有缺项或账号不一致，本次不会生成导入串。签名密钥可能随登录变化，不能混用其他页面或旧账号的数据。
