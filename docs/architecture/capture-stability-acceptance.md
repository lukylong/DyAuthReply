# 采集稳定性验收门槛（候选改动，未发布）

## 原则

不再以“某次导入成功”或“单元测试通过”替代完整采集验收。下列真实验收有未通过/未执行项时，不创建发布标签。用户明确批准时，可在备份并验证回退后安装本地候选；本地候选不等于稳定发布。签名材料配套、同会话、正式 UIFID、真实 Token 与设备采样要求不放宽。真实验收只使用明确批准的账号；采集验收不等于消息发送验收。

## 已发现并补强的分支

- CDP 页面脚本异常不再静默解释成“仍缺字段”；导航结果含 errorText 时不推进阶段，不丢弃创作者材料。
- 每个 CDP 批次的发送与响应共同受一个截止时间限制；连接已关闭时结束采集，不继续空轮询。
- 启动、连接、读取及身份校验可被取消；确认阶段继续检查窗口存活与总超时。
- 正在执行的导入不允许被取消或迟到错误覆盖；取消/失败先保存旧窗口资源句柄，避免清理到后开的窗口。
- 增加 progress_fresh：读取失败时隐藏过时字段状态；UI 轮询使用会话编号与请求序号隔离迟到响应，取消失败不假装已关闭。
- 扩展只把预期域名的已初始化文档视为加载成功，不能把 about:blank 的 complete 当作成功；资料查询前后与最终分域快照核对同一会话。
- Cookie/脚本/网络采样读取有时间上限，页面瞬时读取失败有限重试，错误不残留旧导入串；缺失字段仍阻止导出。
- 设备采样子上下文监听是待真实验证的候选：只接受该受控页面中明确许可的登录域、默认执行上下文的有界样本，拒绝外域、销毁上下文与异常载荷。不得把此改动解释成已证明现场根因。

## 真实验收（发布前必须分别记录，不冒充模拟通过）

1. 原生隔离新配置：扫码登录 → 创作者材料 → 推荐页 → 完整字段 → 身份一致；不导入、不发送。
2. 重复一次新的冷启动，记录登录后各阶段耗时与清理结果。
3. 原生中途关闭、取消及确认超时：窗口/临时目录清理，原客户端账号不变。
4. 扩展创作者入口与主站入口各一次；另测关闭 popup 的完整生命周期，不能仅用正常 finally 场景代替。
5. Windows 构建/安装/运行中升级回归必须通过。2026-10-17 用户明确确认本次 Windows 只做 CI 构建/安装回归，发布说明注明未做真实扫码验收；不得把 CI 冒充真实扫码。
6. 若还缺设备采样或其他必需字段，真实验收判未通过；不能修改布尔状态、伪造字段或忽略校验来通过。

## Bug Analysis: 采集测试通过但真实流程停在精选

### 1. Root Cause Category
- **Category**: D/E - Test Coverage Gap / Implicit Assumption。
- **Specific Cause**: 把导航 URL 或点击返回当作推荐挂载证据；初版鼠标候选又把整页 complete 当作可点击前置条件。可见导航与视频/外部资源全部加载完并不同步。

### 2. Why Fixes Failed
1. 无名 Cookie 修复解决一种真实解析错误，却不足以验证整个采集链。
2. 保留创作者页面补齐异步采样后，手工切推荐成功仍不等于自动流程成功。
3. 单次 DOM 点击缺少结果校验与有限重试；完整文档加载等待又阻塞了可交互导航。
4. 本轮组合候选（正常鼠标事件、interactive/complete、可见性与遮挡检查、完整字段验证）在实机通过；未单独 A/B 分离每项对真实成功的贡献，不能将某一个改动夸大为唯一根因。

### 3. Prevention Mechanisms
| Priority | Mechanism | Specific Action | Status |
|---|---|---|---|
| P0 | Regression | interactive、遮挡、导航回跳和次数上限分别测试 | DONE |
| P0 | Runtime | 不把点击响应或临时 UIFID 当成功，最终校验完整字段及身份 | DONE |
| P0 | Acceptance | 安装包摘要与运行服务身份核对，再记录真实 UI 和接口终态 | DONE |
| P1 | Repeatability | 重复冷启动、扩展关闭 popup 与 Windows 场景 | TODO |

### 4. Systematic Expansion
扩展与原生输入机制不同；扩展目前不是 CDP 鼠标实现。不得用原生本机通过替代扩展验收，也不以采集成功替代发信送达验收。

### 5. Knowledge Capture
项目当前没有 .trellis 工作目录，本记录保存在现有 architecture 文档中，不创建虚构任务或 journal；相关代码与测试仍为未提交候选。
